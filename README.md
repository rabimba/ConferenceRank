# ConferenceRank

> One-stop shop to evaluate computer-science conference venues: ICORE/CORE ranks, rank history, multi-decade acceptance-rate trends, upcoming submission deadlines (AoE), and top publishing institutions.

🌐 **Live Website:** [https://rabimba.github.io/ConferenceRank/](https://rabimba.github.io/ConferenceRank/)

Deployed automatically to GitHub Pages via GitHub Actions.

## Features

- **Rankings**: Complete CORE / ICORE rankings with multi-year rank progression (A*, A, B, C).
- **Upcoming Deadlines**: Submission deadlines for 300+ venues with live AoE countdown timers, 1-click Google Calendar sync, and `.ics` iCalendar export.
- **Target Watchlist**: Zero-login private conference tracking stored locally in your browser with deadline reminder alerts.
- **Acceptance Rates**: Historical acceptance statistics (accepted, submitted, rates) spanning decades for top-tier venues (systems, theory, databases, networks, security, AI/ML, NLP, vision, graphics).
- **Venue Suggester**: Paper abstract matching using TF-IDF lexicon and CORE rank tiering to suggest target venues.
- **Interactive Visualizations**: Interactive selectivity landscape, acceptance rate timelines, topic share charts, and direct side-by-side venue comparisons.
- **Data Sources**: Integrated from CORE, csconferences, ccf-deadlines, ai-deadlines, sec-deadlines, Paper Copilot, lixin4ever, OpenAlex, and DBLP.
- **Automated Updates**: Scheduled GitHub Actions workflows automatically refresh statistics weekly and redeploy to GitHub Pages.

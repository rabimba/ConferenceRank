# ConferenceRank

> One-stop shop to evaluate computer-science conference venues: ICORE/CORE ranks, rank history, multi-decade acceptance-rate trends, topics, and top publishing institutions.

Deployed automatically to GitHub Pages via GitHub Actions.

## Features

- **Rankings**: Complete CORE / ICORE rankings with multi-year rank progression.
- **Acceptance Rates**: Historical acceptance statistics (accepted, submitted, rates) spanning decades for top-tier venues (systems, theory, databases, networks, security, AI/ML, NLP, vision, graphics).
- **Data Sources**: Integrated from CORE, csconferences, ccf-deadlines, Paper Copilot, lixin4ever, OpenAlex, and DBLP.
- **Interactive Visualizations**: Interactive scatter plots, acceptance rate timelines, topic share charts, and direct side-by-side venue comparisons.
- **Automated Updates**: Scheduled GitHub Actions workflows automatically refresh statistics weekly and redeploy to GitHub Pages.
